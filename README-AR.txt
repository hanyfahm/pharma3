تطبيق صيدليتي — إدارة المخازن والفواتير
==========================================

طريقة التشغيل على جهازك:
1. تأكد من تثبيت Node.js (الإصدار 20 أو أحدث) من https://nodejs.org
2. على ويندوز: اضغط مرتين على ملف "تشغيل_التطبيق_ويندوز.bat"
   أو عبر موجه الأوامر (Terminal):
   npm install
   npm run dev
3. افتح المتصفح على العنوان: http://localhost:3000

ملاحظة:
- بياناتك الحالية محفوظة في الملف: data/pharma-db.json
- للعمل الجماعي عبر الشبكة المحلية، يطبع التطبيق رابط الشبكة تلقائياً عند التشغيل.
